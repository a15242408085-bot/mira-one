# Vision Pro

按 StringTune 的滚动叙事重做的概念站。黑场巨字、头显随滚动分开，再进入浅色圆角舞台与功能卡片。主产品是 Vision Pro。

这是一件概念演示，不是 Apple 官方网站。

## 本地预览

```bash
python3 -m http.server 5173
```

打开 [http://localhost:5173](http://localhost:5173)
